How does binary search work?

Binary search works on a sorted list. It checks the middle element and keeps only the half that may contain the target. Use Search Word to see this process step by step.

🎓 Understand Binary Search

↕️

1. Sorted Data

Words must be in alphabetical order before binary search can determine which half to keep.

🎯

2. Find the Middle

Calculate the middle index using (low + high) // 2 and inspect the word at that position.

✂️

3. Reduce the Range

Keep the left or right half based on alphabetical order. Repeat until the target is found or the range is empty.

Algorithm efficiency

Why is binary search efficient?

Each unsuccessful step discards approximately half of the remaining candidates. Its worst-case time complexity is O(log n), provided the input is sorted and random access is available. The iterative implementation uses O(1) auxiliary search space, excluding the saved visualization steps.
